# Taxi Fare Prediction

## Description
A **Flask web application** to predict taxi fares based on pickup and drop locations, ride type, and number of passengers.  
The app stores ride history in **SQLite**, displays interactive maps using **Leaflet.js**, and shows fare trends with **Chart.js**.

## Features
- Predict taxi fare based on multiple inputs.
- Store and view ride history.
- Search suggestions for pickup and drop locations.
- Interactive map display of rides.
- Fare trend chart visualization.
- Responsive and user-friendly design.

## Technologies Used
- Python, Flask
- SQLite
- HTML, CSS, JavaScript
- Leaflet.js (Maps)
- Chart.js (Charts)
